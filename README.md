# 淮海战役作战态势图 · 交互推演

一张可交互的淮海战役（1948.11.06 — 1949.01.10）作战态势地图：拖动时间轴或点播放，看两军军标在徐州、碾庄、双堆集、陈官庄之间一步步挪动；正文改成**点词联动**——点「十三纵」只闪十三纵，点「浍河渡口」只闪那个渡口；鼠标停在部队词上，弹出番号、全称、主官、编制、当日任务与结局。

主线产物是**一个自包含的 HTML 文件**（`淮海战役作战态势图.html`），双击即可在浏览器打开，不依赖网络、不依赖构建工具。地图由 Canvas 手绘，图表部分的 ECharts 5.5.0 已内联进文件。

## 快速开始

1. 下载或克隆本仓库；
2. 双击 `淮海战役作战态势图.html`，用 Chrome / Edge / Safari 打开；
3. 拖动时间轴，或点「播放」看 66 天怎么走完；播放键旁有「慢 / 中 / 快」三挡，默认慢档约两秒一天。

无需 Node、无需 npm、无需服务器。

```bash
git clone https://github.com/shishi11/huaihai-campaign-interactive-map.git
cd huaihai-campaign-interactive-map
```

## 功能一览

### 时间轴与阶段
- 时间轴两端各延伸一段：**战役准备（10.11 — 11.05）** 与 **战役之后（01.11 — 01.31）**，战役本身 66 天居中；分列五个阶段按钮。
- 36 幕事件，每幕配概要 / 详述两版正文；详述里番号、村落、河道更密，切换时自动上细图。
- 「下一事件」按钮：地图连续动画推进到下一幕，日期、军标、箭头同步生长。
- 播放三挡速度（慢 / 中 / 快），播放中可随时切换，慢档全程约两分多钟。

### 地图与军标
- 两种底图：**简图 / 细图**（细图加绘山地晕纹、支流、县镇、铁路与河渠名，线条按真实走向弯曲，与简图共用同一份路径数据）。
- 两种军标：**文字 / 符号**（1948 年参谋作业符号；悬停即显示番号）。
- **26 支兵团 / 纵队级军标**（解放军 17 支、国民党军 9 支），另附 55 枚军 / 师 / 旅 / 团 / 营分队小符号；放大 1.25 倍以上才显番号，避免糊成一片。
- 七纵、十纵、十一纵、十三纵各为独立军标，按各自时间线走完：十三纵「临城—曹八集—大许家—双堆集—陈官庄」，七纵「鲁南—曹八集—大许家—双堆集—陈官庄」；鲁中南纵队「临沂—郯城—徐东南—陈官庄」。
- 渡口、桥、村落等点要素单独上图（运河站、运河铁桥、浍河渡口、鲁楼、大王庄等），河名、线名只标名称，点名称闪线条，点线条闪名称。
- 被歼 / 起义的兵团在片尾播放歼灭动画，并在兵团视角面板写明终局（自戕、被俘、潜逃、击毙）。

### 点词联动
- 正文里的部队词、地名词带下划虚线，可单独点：点「十一纵」只闪十一纵，点「运河铁桥」只闪桥图与桥名，点「浍河渡口」只闪渡口方块；不再整句一起闪。
- 悬停部队词弹信息卡：番号、全称、主官、编制、该阶段在做什么、结局（被俘 / 击毙 / 潜逃 / 起义）；全屏（含降级铺满）时卡片仍显示。
- 点词后地图局部放大到该目标，方便看「谁在哪里做什么」。

### 兵团视角
- 任一军标弹窗里点「以该兵团视角看战役 →」，镜头跟随该部走完全程。
- 面板显示当日命令（无留档电令时写作“作战意图”，据图上路线与态势推断）。
- 每一阶段与之直接交战的部队描红虚线框、协同部队描蓝虚线框，阶段一过自动失效、无关部队转灰。

### 全屏与移动端
- 推演台可一键全屏，事件卡、地图、时间轴一起铺满；全屏内点词、悬停照常。
- 手机竖屏提示转横屏，横屏时地图居左、事件卡居右，军标与时间轴不被遮挡。

### 史料与出处
- **36 条资料来源**（中央党史和文献研究院、国防部网 / 解放军报、求是网《毛泽东选集》、中国军网、人民网党史、央视网、安徽省人民政府、淮海战役纪念馆展陈等），每条事件引文标注「见资料来源 N」。
- 每幕事件卡下方有当幕史料条；关键命令（COMMANDS）逐条注明出处编号。
- 「双方的账本」一节列 62 条参战序列（解放军 / 国民党军各军、师、团及地方部队），并注明主官与该部本役作为。

## 技术实现

| 项 | 做法 |
| --- | --- |
| 交付形态 | 单个 `.html`，CSS / JS 全部内联，ECharts 5.5.0 内联 |
| 框架 | 无。原生 JS，两个 IIFE（地图引擎 / 交互层），通过 `window.HH` 命名空间通信 |
| 地图 | Canvas 2D 手绘，经纬度投影范围 E114.85–119.55 / N32.30–35.30，余弦纬度校正 |
| 数据 | 部队、事件、命令、路线、河流、铁路、桥梁、村镇均以字面量固化在 JS 内 |
| 图表 | 力量对比等静态图表用内联 ECharts |
| 交互 | 时间轴、三挡播放、事件推进动画、军标命中检测、点词联动、悬停信息卡、局部放大、河流 / 线条闪烁 |
| 词条解析 | 番号别名按词长降序匹配（「十一纵」先于「一纵」），顿号并列番号逐项认人；同一写法可指向多支部队（如「华野七纵、十三纵」） |

## 开发与修改过程

这份产物不是一次写完的，而是二十余轮“提需求 — 改 — 截图验收”迭代出来的。主要轮次：

1. **底图分级**：加「简图 / 细图」切换，细图补地形晕纹与支流。
2. **军标两态**：文字标与参谋符号可切，符号态悬停显示番号。
3. **点句联动**：正文分句可点，句中地名 / 部队在图上闪烁，并局部放大。
4. **地理核查**：补运河铁路桥、津浦路、浍河、大运河、黄河故道、颍河、淮河等线名与位置。
5. **事件推进**：每幕加「下一事件」，地图连续动画过渡，形成时间上的连贯。
6. **番号上图**：军、师、团级分队以更小符号上图；被歼部队加歼灭动画。
7. **兵团视角**：单线跟随动画 + 命令 / 作战意图面板。
8. **详述 / 概要**：两版正文可切，详述自动切细图；详情卡加滚动条。
9. **线条统一**：细图不再另画一套线，与简图共用同一份路径数据；河线改为曲线拟合。
10. **点线闪名**：点线身只闪名称，点名称闪线 + 名。
11. **片尾歼灭误判修复**：华野 / 中野各部“存续到片末”曾被判成“被歼”，改为只对带 `gone` 标记的部队播歼灭动画。
12. **结局与关系**：兵团视角写明被歼详情或战后去向（如第六兵团 1949.1.10 起南撤滁县、1.16 撤离蚌埠时炸毁淮河铁桥），并按阶段高亮交战方 / 协同方。
13. **时间轴两端延伸**：补战役准备 4 幕、战役之后 5 幕，阶段按钮扩为五段。
14. **弹窗遮挡修复**：靠图框下沿的军标弹窗改按实测尺寸上翻 / 翻边，保证「以该兵团视角」按钮始终可点。
15. **点句改点词**：整句联动取消，改为只闪被点的那一个部队 / 地点；河流、铁路词闪线 + 名，渡口、村落闪点位。
16. **悬停信息卡**：部队词悬停显示番号、全称、主官、编制、当日任务与结局；军、师、团分队同样可查。
17. **军标拆分**：原「华野七纵、十三纵」合用一个军标、且只在双堆集出现，导致点「十三纵」被夹到宿县；拆成七纵、十三纵两枚独立军标，各自从鲁南 / 临城起走完全程；十纵、十一纵也从「七、十、十一纵」中析出。
18. **地名与坐标订正**：「碾庄」改「碾庄圩」；运河站、运河铁桥重排标签，不再被军标压住只剩“运河”；浍河折点由 33.72° 南移到渡口所在的 33.556°，浍河渡口回到河心。
19. **全屏浮卡修复**：信息卡原挂在页面最外层，全屏只渲染推演台子树时被隐藏；改为随全屏容器挂载。
20. **播放速度**：加慢 / 中 / 快三挡，慢档约两秒一天。
21. **参战序列订正**：鲁中南纵队原被标「本役未参战」，与正文矛盾，改为郯城歼山东保安第一旅、徐东南阻援、追歼杜聿明集团，并补上该部军标。

## 用豆包的过程

这个项目全程在豆包（办公模式 / 本地电脑环境）里完成，流程大致是：

1. **需求拆解**：每一轮先把口语化的要求翻成可验证的清单（例如“点线名要闪”要拆成“命中热区、闪烁对象、闪烁时长、是否放大”），再动代码。
2. **史料核查**：关键事实（黄百韬自戕、邱清泉被击毙、李弥潜逃、黄维被俘、李延年撤守蚌埠炸桥、鲁中南纵队攻郯城等）逐条对照公开史料，写进数据时同时登记来源编号，避免“看起来像”的表述。
3. **增量改单文件**：不做重构、不引入框架，每次只改必要的函数；改前先读原文件，改后用浏览器实跑。
4. **截图验收**：用 Chrome headless 生成快照页，按不同日期相位截图（准备段、碾庄、双堆集、陈官庄、战后），再逐张比对军标位置、标签遮挡、面板内容；动画类效果用固定虚拟时间预算截取关键帧。
5. **踩过的坑**（也写在这里，免得下次再踩）：
   - 两个 IIFE 之间必须走 `window.HH`，否则 `ReferenceError` 会被浏览器静默吞掉，表现为“点了没反应”；
   - 歼灭动画曾按“所有 `life[1]` 被跨过”触发，导致华野、中野被误判为被歼，须用 `gone` 标记区分；
   - 短写法会抢先匹配：「十一纵」曾被认成「一纵」，改为番号统一按词长降序；
   - 判断“是不是河名”若用包含关系，「运河站」「运河铁桥」「浍河渡口」都会被河流吞掉，词条级必须整词比对；
   - 全屏只渲染全屏元素子树，挂在 `body` 上的浮层会消失，信息卡须挂进推演台容器；
   - 同一个番号在不同时间隶属不同建制（七纵、十三纵前期在山东兵团、后期南下双堆集），一个军标塞两支部队必然错位，只能拆开；
   - 弹窗定位不能写死高度，必须先量实际尺寸再夹取边界。
6. **交付**：每一轮改完直接把 HTML 交付给用户验收，下一轮在其基础上继续改，而不是另起一份。

## 已知限制

- 军标为示意位置，按日插值移动，不等于逐日实测坐标；仅供理解战役进程，不作军事研究依据。
- 徐州—陈官庄一带在 12 月中旬前后军标密集，小屏需放大或点按读名。
- 详述正文中个别细节依赖通行战史叙述，未逐条标注页码级出处。
- 事件推进动画为固定时长插值，不是严格按史实时间比例。
- 部分支队（如渤海纵队、第三十五军）只标主要节点，未逐日细化。
